# Project Rules & Conventions

## Language & Tone
- All code comments, docstrings, variable names, function names, and technical documentation MUST be written in professional English.
- All commit messages MUST follow the Conventional Commits specification in English.
- All log messages, console messages, and exception strings MUST be written in English.

## Formatting & Aesthetics
- NO EMOJIS anywhere in the codebase:
  - No emojis in log statements or console output.
  - No emojis in UI strings, button labels, or placeholders.
  - No emojis in comments, docstrings, or markdown files.
  - No emojis in commit messages or git logs.

## Quality & Maintainability
- Keep code clean, explicit, and concise.
- Adhere to the established repository conventions and project structure.
- Never use unnecessary grep commands when direct tools or targeted reads provide the required information.
